POS Hardware Bridge API

Print receipts, kitchen tickets and A4 invoices from any POS. The bridge on the shop computer sets up the printers. Your POS only picks a printer by name, or uses the default.

POS on the printer computerCall http://127.0.0.1:9191 with the access token from the bridge.
Phone, tablet or till on the shop Wi-FiPair once with the code shown in the bridge (POST /pair), then print with the device token.
Any device, through your POS backendImplement the print station protocol. Works on any network, including from hosted web POS.
