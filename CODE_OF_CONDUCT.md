# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, patient and respectful. Critique code and ideas, not
people. Harassment, insults and discriminatory language aren't accepted in
issues, pull requests, discussions or anywhere else the project lives.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer,
[@Thisarahetz](https://github.com/Thisarahetz), privately (contact details are
on their GitHub profile). Reports are kept confidential. The maintainer may
remove comments, close threads or block anyone who breaks this code of conduct.
